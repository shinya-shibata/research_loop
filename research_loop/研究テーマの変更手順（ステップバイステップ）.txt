 研究テーマの変更手順（ステップバイステップ）
ステップ 1: 
config.yaml
 を開く
フォルダー直下の 
config.yaml
 をエディタで開きます。

ステップ 2: project セクションの 2 箇所を書き換える
先頭にある id と topic を、新しい研究テーマに合わせて書き換えて保存します。

# 変更前の例
project:
  id: "ancillary_stat_project"
  topic: "補助統計量の存在条件についての検証"

# 🔻 新しいテーマに変える場合の例 🔻
project:
  id: "clt_convergence_project"                         # 💡 ① プロジェクト識別ID（英数字・アンダースコア）
  topic: "高次元データにおける中心極限定理の収束速度の評価"   # 💡 ② 具体的な研究テーマ


重要ポイント：なぜ id も変える必要があるのか？
topic: AI（GeminiやDeepSeekなど）に指示として渡される「研究の課題テキスト」です。
id: データベース（SQLite）内に保存される**「セーブデータの識別名」**です。
id を新しい名前（例: clt_convergence_project）に変更することで、過去の研究のチェックポイント（セーブデータ）と混ざることなく、完全に新しい研究プロジェクトとして 1 ラウンド目からフレッシュにスタートできます。

🚀 実行方法
config.yaml
 を保存したら、通常通りターミナルで実行するだけです。

python graph.py

実行されると、config.yaml で設定した新しい id と topic が自動的に読み込まれ、新しい研究ループが開始されます。
