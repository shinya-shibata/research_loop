# 環境設定ガイド (Slack)




1. SLACK_WEBHOOK_URL の設定（任意）
研究ループが一時停止（Pause）した際に、Slack へ「一時停止しました。レビューしてください」等の自動通知を送信するための設定です。

Note: Slack 通知が不要な場合（ターミナル表示やファイル生成の確認のみで良い場合）は本手順をスキップ可能です。.env の SLACK_WEBHOOK_URL= は空欄のままで動作します。

手順
Slack App 作成ページへアクセス

ブラウザで Slack API: Applications にアクセスします。

アプリの作成

「Create New App」 ボタンをクリックし、「From scratch」 を選択します。

App Name: 任意の名前（例: Research-Bot）

Development Slack Workspace: 通知を受け取りたいワークスペースを選択

「Create App」 をクリックします。

Incoming Webhooks の有効化

左側サイドメニューの 「Incoming Webhooks」 をクリックします。

画面右上のトグルスイッチ（Off）をクリックして On に切り替えます。

Webhook URL の発行

ページ最下部の 「Add New Webhook to Workspace」 ボタンをクリックします。

通知を送信したい Slack チャンネル（例: #general や #研究ログ）を選択し、「許可」 をクリックします。

URL の取得と .env への設定

発行された Webhook URL の横にある 「Copy」 ボタンをクリックします。

プロジェクト直下の .env ファイルを開き、SLACK_WEBHOOK_URL に貼り付けます：


SLACK_WEBHOOK_URL=[https://hooks.slack.com/services/YOUR/WEBHOOK/URL_HERE](https://hooks.slack.com/services/YOUR/WEBHOOK/URL_HERE)
